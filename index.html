茶番会社

YouTubeショートチャンネル「Mr.&Mrs.茶番」の運営チームです。海外の夫婦・カップル・友だちの面白い瞬間を、関西弁の字幕で紹介しています。

このアプリについて

「茶番会社」は、チャンネル運営者が自分のチャンネルの数字だけを読み、動画づくりの答え合わせに使うための社内ツールです。

  • YouTube Data API と YouTube Analytics API を読み取り専用で使います
  • 動画の投稿・削除・変更は行いません
  • 運営者本人だけが使います（一般には公開していません）
