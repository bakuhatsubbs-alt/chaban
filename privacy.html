プライバシーポリシー

最終更新：2026年11月6日

1. 取得する情報

本ツールは、Googleの許可を得て、運営者自身のYouTubeチャンネルについて次の情報を読み取ります：チャンネル名・登録者数・動画の一覧と公開予定・再生回数やエンゲージビュー・視聴維持率・視聴者の年齢層／性別／国／流入元（いずれもYouTubeが集計した統計）・推定収益。

2. 使い道

運営者が自分の動画の成果を振り返り、次の動画づくりに活かすためだけに使います。広告・販売・第三者への提供には使いません。

3. 保存場所と処理

読み取った情報と許可証は、運営者のパソコンの中に保存します。許可証は外部に送りません。読み取った統計の集計・振り返りには、運営者が契約しているAIアシスタント（Anthropic社のClaude）を使うことがあり、その際は統計の内容がその提供元で処理されます。それ以外の第三者には送りません。

4. 権限について

読み取り専用の権限だけを求めます。動画の投稿・削除・設定の変更はできません。

5. 許可の取り消し

Googleアカウントの サードパーティ接続の管理 から、いつでも許可を取り消せます。

6. Google API サービスの利用について

本ツールによるGoogle APIから受け取った情報の利用は、Google API サービスのユーザーデータに関するポリシー（限定使用の要件を含む）に従います。また YouTube利用規約 と Googleプライバシーポリシー が適用されます。
